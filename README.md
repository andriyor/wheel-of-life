# Wheel of Life

A calm, ADHD- and anxiety-friendly Wheel of Life. Four short steps:

1. **Check in** — rate 8 areas 1–10 (sliders, or tap/drag the wheel). Tick *Not in my control right now* or *Good enough for this season* to let an area go.
2. **What matters** — pick up to 3 core values; each one adds a ★ to the areas it feeds.
3. **Tradeoffs** — spread 10 energy points across the week. When they run out, the app offers to move one from the least important area.
4. **Focus** — at most 3 areas (gap × importance, skipping what you let go), each with tiny 5-minute steps to tick off.

Answers stay in your browser (localStorage).

```sh
pnpm install
pnpm dev     # http://localhost:5173
pnpm test    # priority logic
pnpm build
```
